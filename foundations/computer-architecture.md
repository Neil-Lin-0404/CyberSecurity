# 計算機結構

[數學](mathematics.md) · [共同基礎](../02-CORE-FOUNDATIONS.md) · [作業系統](operating-systems.md)

學習類型：概念為主，組語是程式技能。這一頁讓你看懂軟體與硬體的邊界，不是微架構研究手冊。

## 要建立的模型

處理器執行指令。暫存器是指令直接使用的小儲存。記憶體階層從暫存器、快取到主記憶體再往外，愈遠愈慢。程式看到的位址通常是虛擬位址，由硬體與作業系統一起轉成實體位址。中斷讓裝置或例外能打斷目前的指令流。特權級決定目前能執行哪些指令、能碰哪些記憶體。

深度：上述模型 L1，REQUIRED，對象是系統安全、逆向與任何會談隔離的人。

## 主題深度

| 主題 | 深度 | 重要性 | 對誰重要 |
|---|---|---|---|
| CPU 如何執行指令 | L1 | REQUIRED | 所有系統方向 |
| 指令集架構 ISA | L1 | REQUIRED | 逆向、系統、硬體 |
| 暫存器與呼叫慣例 | L1 | RECOMMENDED；逆向則 REQUIRED | 讀反組譯 |
| 記憶體階層與快取 | L1 | RECOMMENDED | 效能與側信道的前提 |
| 虛擬記憶體的硬體角色 | L1 | REQUIRED | 與作業系統一起學 |
| x86-64 基礎 | L1 | RECOMMENDED | 你的電腦與許多二進位 |
| ARM 基礎 | L0 | OPTIONAL | 嵌入式與部分雲端主機 |
| 中斷 | L1 | RECOMMENDED | 作業系統與驅動邊界 |
| 特權級 | L1 | REQUIRED | 使用者態與核心態 |
| 側信道的微架構細節 | 不學 | ON-DEMAND | 只有該研究問題 |

x86-64 先認識：通用暫存器、堆疊、呼叫時參數與返回值大致放哪裡、`call` 與 `ret` 在做什麼。ARM 或 RISC-V 只要知道「暫存器機器、載入與儲存」的 L0。xv6 使用 RISC-V，若你做 MIT 6.1810 的實驗，再把 RISC-V 呼叫慣例升到 L1，見 [作業系統](operating-systems.md)。

## 和三個安全方向的關係

系統安全使用特權級、虛擬記憶體與中斷，來理解隔離為什麼不能只靠程式自覺。你要能說明：使用者程式不能任意執行特權指令。

逆向工程使用 ISA 與呼叫慣例，把位元組對回控制流。入門用你自己編譯、關掉最佳化的小程式。工具與樣本限制見 [模組 06](../modules/06-malware-analysis-and-reverse-engineering.md)。

硬體安全使用信任根、開機與匯流排的概念。快取階層只到能讀懂「硬體狀態可能受共用影響」的 L0。側信道的實驗設計、量測參數與利用步驟不在本頁，也不在入門路徑。

## 練習

在你自己的 Linux 虛擬機：

1. 編譯一個印出數字的 C 程式，用 `objdump -d` 或編譯器輸出組語，找到 `main` 與一次函式呼叫。
2. 寫下三個暫存器在這段裡似乎被用來做什麼，以及你還不確定的兩個地方。
3. 用一句話說明這個練習還沒有觸及核心態。

## 自測

你能畫出一條指令從取值、解碼到讀寫暫存器的簡圖，並標出虛擬位址在哪一步仍不是實體位址。你也能說出快取一致性與投機執行是以後的主題。

## 可延後

管線、亂序執行、分支預測、TLB 項目的替換政策、GPU、可信執行環境的產品差異。模組 08 會在需要時把它們從 L0 升起。
