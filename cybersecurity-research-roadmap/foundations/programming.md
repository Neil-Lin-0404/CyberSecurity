# 程式

[計算機科學](computer-science.md) · [共同基礎](../02-CORE-FOUNDATIONS.md) · [軟體工程](software-engineering.md)

學習類型：程式與實作。數學只在你要分析複雜度或密碼實作時才插入，見 [數學](mathematics.md)。

你已經寫過 C++，也接觸過演算法、Linux、Git 與網頁開發。這一頁不從「什麼是變數」開始，只補資安研究會反覆用到、而課程常常假設你會的部分。

## 語言怎麼分配

| 語言或技能 | 定位 | 現在的深度 | 原因 |
|---|---|---|---|
| C | REQUIRED，系統與網路方向 | L2：能讀指標、記憶體與錯誤處理 | 作業系統、網路堆疊與許多研究系統用 C |
| C++ | REQUIRED 的延伸 | L1–L2：能讀你會遇到的研究程式 | 你已有基礎；重點是記憶體與生命週期，不是語言全集 |
| Python | REQUIRED | L2：檔案、二進位、資料處理、小實驗 | 擷取分析、實驗腳本、圖表與膠合工具快 |
| Linux 命令列與 shell | REQUIRED | L2：管道、權限、程序、文字處理 | 實驗環境與日誌幾乎都在這裡 |
| Git | REQUIRED | L1：分支、可重現的提交 | 你已會基本操作；補的是實驗版本紀錄 |
| 偵錯 | REQUIRED | L2：`gdb` 或等效工具能停下來看記憶體與呼叫堆疊 | 沒有偵錯，逆向與系統閱讀會停在猜測 |
| Rust、Go | OPTIONAL | L0，直到專案使用 | 新的系統研究常見，但不是入門門檻 |
| JavaScript | ON-DEMAND | 依 Web 模組 | 只在你抽樣 Web 或瀏覽器安全時加深 |
| 組語 | ON-DEMAND | 見 [計算機結構](computer-architecture.md) | 逆向與系統安全才升到 L2 |

C 與 C++ 讓你看見記憶體、表示方式與系統呼叫的成本。Python 讓你在假設還不穩時快速整理觀察。研究裡兩者常一起出現：C 或 C++ 產生或處理效能敏感的部分，Python 負責實驗與分析。不要為了「專業」把所有腳本改寫成 C++。

## 現在要補的缺口

### 記憶體、指標與參照

概念類型：程式。深度 L2。

你要能說明：物件存在哪裡、誰負責釋放、指標與 C++ 參照差在哪、緩衝區大小從哪裡來。這是系統安全與自行實作解析器的 REQUIRED，因為研究常在讀「長度欄位是否可信」。

可延後：配置器內部、自訂記憶體池。標成 ON-DEMAND。

自測：寫一個小程式，故意讓長度檢查失敗，用偵錯器指出越界讀發生的位置。只在你自己的程式上做。

### 行程、執行緒與並行

概念加上程式。深度 L1。

知道行程不共享位址空間、執行緒共享，以及資料競爭是什麼。網路伺服器與擷取程式會用到。完整並行理論是 OPTIONAL，除非你的研究問題就是同步。

### 資料結構、演算法與複雜度

你已有基本暴露。研究使用深度保持 L1：能估計一個分析腳本會不會在你的擷取上慢到無法重跑。圖演算法在路由或攻擊圖出現時再學，見 [計算機科學](computer-science.md)。

### 網路程式

程式。深度 L1，主修網路時升到 L2。

用 Python 或 C 寫一個對你自己主機的 TCP 客戶端與伺服器，以及一個只查你指定域名的 DNS 查詢。教材用 [Beej's Guide](https://beej.us/guide/bgnet/) 的客戶端—伺服器章，或 Python 官方 `socket` 文件。不要寫掃描器去探測別人的主機。

### 讀陌生原始碼

研究技能，也是程式技能。深度 L2。

順序：先找入口與資料結構，再追一條正常路徑，最後才看錯誤處理。每次只回答一個問題，例如「這個長度是從封包讀來的還是常數」。xv6 可以當作練習材料，但那是作業系統路徑，不是本週必做，見 [作業系統](operating-systems.md)。

### 偵錯與觀察

`gdb`、編譯器警告、以及把中間結果寫進紀錄。深度 L2。學會在沒有圖形介面的虛擬機裡完成一次回溯。

## 依研究領域的語言重心

| 領域 | 先加深 | 可以保持淺 |
|---|---|---|
| 網路、量測 | Python 二進位與 C 的 socket | 核心模組 |
| 系統安全 | C、偵錯、並行 L1 | C++ 模板進階 |
| 逆向 | C、表示方式、之後的組語 | Python 只負責整理筆記 |
| 密碼實作 | C 或 Rust 的常數時間是以後的事；現在先會用函式庫並知道誤用 | 自製加密演算法 |
| Web | 你已有的網頁經驗加上 HTTP | 前端框架全集 |
| 形式方法 | 任何你能精確描述的語言；工具語言另學 | 為了形式方法改寫全部專案 |

## 練習

1. 用 Git 管理一個 Python 腳本：讀取你自己產生的小檔，印出長度與前 16 個位元組的十六進位。
2. 用 C 或 C++ 配置一個緩衝區，寫入、讀出，並用偵錯器看位址。
3. 寫一個只連接 `127.0.0.1` 的 TCP echo 客戶端與伺服器。

完成標準：三個練習都有提交紀錄，且你能說明每個程式沒有檢查的錯誤。

## 可延後

編譯器最佳化、連結器細節、非同步框架全集、為效能重寫 Python。這些在你的實驗被它們擋住時再列入 Backlog。
