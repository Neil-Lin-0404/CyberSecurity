# 資安研究路線圖

這是一份長期使用的個人知識庫，用來探索資安研究，而不是工具清單或 CTF 通關表。它假設你已有一些 C++、演算法、Linux、Git 與網頁開發經驗，但還沒有正式學過作業系統、計算機結構、計算機網路或大學數學。

目前的探索起點是網路安全：協定、DDoS 偵測、網路量測與歸因。路線圖同時保留其他專長，讓你在承諾主修之前先看過實際的研究工作。

## 使用這份知識庫時要能回答的六個問題

1. 下一步學什麼？
2. 為什麼需要它？
3. 要學多深？
4. 什麼可以延後？
5. 怎樣算懂了？
6. 去哪裡學？

深度用 L0 認識、L1 理解、L2 技術熟練、L3 研究深度。先修用 REQUIRED、RECOMMENDED、OPTIONAL、ON-DEMAND。定義見 [詞彙](GLOSSARY.md)。
