# 研究方法

[學習法](03-LEARNING-METHODOLOGY.md) · [地圖](README.md) · [興趣評估](05-INTEREST-ASSESSMENT.md)

研究是一串可檢查的決定：你主張什麼、證據從哪來、什麼會推翻它、你沒有檢查什麼。

## 流程

1. 選一個你碰得到的系統或問題。
2. 先弄清這個系統在正常情況如何工作。
3. 讀權威文件：規格、官方文件、標準。
4. 找相關學術工作，區分奠基論文與後續結果。
5. 列出系統與論文依賴的假設。
6. 寫成可回答的研究問題。
7. 提出假設：你預期觀察到什麼，以及什麼結果會否定它。
8. 設計實驗或形式分析。
9. 在授權範圍內收集資料。
10. 用事先選定的指標評估。
11. 寫出至少一種替代解釋。
12. 寫出限制與你沒有做的事。
13. 讓別人能依你的紀錄重跑，或明確說明哪些資料不能公開。
14. 用論文、技術報告或實驗紀錄溝通結果。

範本：[研究問題](templates/research-question.md)、[實驗紀錄](templates/experiment-log.md)、[論文閱讀](templates/research-paper-review.md)。

## 這些詞各自指什麼

| 詞 | 在這份知識庫裡的意思 |
|---|---|
| 文獻回顧 | 說明已知結果、它們的條件，以及你的問題落在哪裡 |
| 研究缺口 | 既有工作沒回答、而你的方法有機會回答的具體空白 |
| 假設 | 可被觀察或證明否定的預期 |
| 自變數 | 你刻意改變的條件 |
| 因變數 | 你量測的結果 |
| 基線 | 用來比較的既有方法、空模型或正常行為 |
| 指標 | 事先定義的數量或判斷程序 |
| 實驗對照 | 一次只變一個因素，或明確記錄同時在變的因素 |
| 可重現性 | 他人依紀錄能得到可比較的結果 |
| 統計顯著性 | 在所述模型下，結果不太像純偶然；它不自動等於實務重要性 |
| 效度威脅 | 會讓結論不能推廣或不成立的設計問題 |
| 同儕審查 | 領域研究者在發表前挑戰方法與主張 |

統計顯著性需要樣本與模型。單一條封包或單一目誌不能稱為顯著。若你還沒學推論統計，就報告效果的方向、次數與設定，並把顯著性標成以後的工作。

## 論文怎麼讀

初學者不需要第一次就懂完全文。分三次：

1. 摘要、引言、結論。寫下：問題、主張、你不懂的詞。不懂的詞進 Research Backlog，不要整篇停住。
2. 相關工作與限制。寫下：作者說自己沒做什麼、和誰比較。
3. 方法、評估、結果。只在前兩次確定這篇與你的目標相關時才細讀。

每次閱讀使用 [論文閱讀範本](templates/research-paper-review.md)。

### 各段在回答什麼

| 段落 | 你要抽出的句子 |
|---|---|
| 摘要 | 問題與主要結果 |
| 引言 | 為什麼這個問題值得做、貢獻列表 |
| 相關工作 | 差異，而不只是人名 |
| 方法 | 系統或證明依賴的假設 |
| 評估 | 資料從哪來、基線是什麼、指標是什麼 |
| 結果 | 哪些支持主張、哪些不明顯 |
| 限制 | 作者承認不能外推的地方 |
| 結論 | 與摘要是否一致 |

## 常見的研究技能

- 把「我想讓網路更安全」收成「在這個擷取裡，這個特徵比基線早多少個時間窗超過門檻」。
- 區分規格允許的行為、實作選擇，以及你的資料裡的巧合。
- 保留原始觀察與處理後的表，並記錄指令、版本與時間。
- 主動尋找會推翻假設的證據。
- 在寫作時把不確定性留在句子裡，尤其是歸因與人員身份。

## 最小的一輪研究練習

選 [初學專題](projects/beginner-projects.md) 的一個項目，額外寫下：假設、你改變的唯一條件、基線、一個替代解釋、一個限制。這還沒有達到可發表，但已是研究動作。

會議、預印本與審查文化見 [研究與學術](06-RESEARCH-CAREER-AND-ACADEMIA.md)。
